# PS-007 Monitor Web SOC Dashboard (Frontend)

A modern, real-time Security Operations Center (SOC) web dashboard for the **PS-007 Privacy-Aware IPv6 IoT Security Monitor**.

---

### Architectural Design: Pure Passive Observer
* **Zero Client/Router Powers:** The dashboard is strictly an observational window into whatever traffic the monitor captures and analyzes. It cannot control clients, execute commands, or simulate attacks.
* **Dual Data Pipeline:**
  1. **Real-time Live Events:** Direct sub-millisecond connection to native WebSocket (`ws://localhost:8765`).
  2. **Atomic Snapshot Recovery:** Fetches state from `GET /api/state` (generated by `monitor.py` every second) for instantaneous state sync on page load/refresh.
* **Privacy Verification:** Continuous runtime audit confirming 0 hardware MAC addresses (`Ether.src`) are ever read or stored.

---

### Visualizations Included
1. **Interactive Network Topology Map:** HTML5 Canvas rendering `r1` (Gateway), `s1` (Switch), `m1` (Monitor), and `h1`–`h5` (IoT Nodes) with animated packet flow particles and warning beacon pulses.
2. **Threat Telemetry & Anomaly Gauges:**
   - RFC 4861 NDP Token Bucket Fill Bar (drain vs replenishment).
   - CUSUM Cumulative Drift indicator (stealth low-and-slow flooding detection).
   - Target Scanning Cardinality meter (unique targets per 5s sliding window).
   - RFC 6105 RA-Guard verification box.
3. **Active Monitored Fleet Table:** Displays Role, Status (`ACTIVE`, `IDLE`), Ephemeral Pseudonym ($P$), Active SLAAC Address, Rotations, Packets, and Ingress Port Anchor.
4. **RFC 8981 Address Rotation Chains:** Visual history tracking `[ACTIVE]` and previous `[PREV 1..N]` addresses linked to each pseudonym.
5. **Real-Time Security Alerts Stream:** Live feed of `ROGUE_RA` and `NDP_ABUSE` events with timestamps and evidence.
6. **Time-Travel Replay Scrubber:** Scrubber bar allowing the user to pause, scrub, and replay historical test sessions from `events.jsonl`.

### How to Run

#### 1. Ensure Monitor is running:
In Terminal 1 (inside Mininet namespace or shell):
```bash
cd ~/Documents/network/src
sudo python3 monitor.py
```

#### 2. Start the Flask Web Dashboard:
In Terminal 2:
```bash
cd ~/Documents/network/src/frontend
python3 app.py
```
*(Or from the project root: `python3 frontend/app.py`)*

#### 3. Open in Browser:
Navigate to:
```
http://localhost:5000
```
*(or specify a custom port: `python3 app.py --port 8080`)*
